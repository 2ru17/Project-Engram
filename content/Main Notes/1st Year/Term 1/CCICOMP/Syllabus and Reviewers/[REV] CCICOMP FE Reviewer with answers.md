## Overview

This document is a comprehensive Final Exam Reviewer for CCICOMP (Term 1, AY 2024-2025). It covers a wide array of topics including Computer Hardware (CPU, Motherboard, Memory, Storage, I/O), Software (OS, Applications), Virtualization, Internetworking, Cybersecurity, the Software Development Process, and Databases. The review is structured in a Q&A format to aid test preparation.

## Theoretical Framework & Exam Review Q&A

### 1. Computer Hardware - CPU and Motherboard **Clock Speed:** The clock speed of a CPU is determined by the **System clock**. **Multicore Architecture:** Enhances performance by allowing simultaneous execution of multiple instruction threads. **System Bus:** Its role on a motherboard is to **transfer data between the CPU, memory, and peripherals**. **Control Unit:** Critical for managing data flow within the processor during the fetch-decode-execute cycle. **Chipset:** Primarily controls **communication between the processor and external devices**.

### 2. Computer Hardware - Memory and Storage **DRAM:** A type of memory that requires refreshing thousands of times per second to retain data. **SSDs vs HDDs:** The primary advantage of SSDs over HDDs is **faster read/write speeds**. **Cache Memory:** Used to **temporarily store frequently accessed instructions and data**. **Optical Storage:** A **DVD** is an example of optical storage. **Memory Hierarchy:** The CPU accesses **L1 Cache** first.

### 3. Computer Hardware - I/O Devices **Touchscreens:** **Resistive screens rely on conductivity** while capacitive screens are different (Wait, resistive screens rely on pressure, capacitive on conductivity. *Correction based on options:* Option C or D? The correct distinction: Resistive screens are pressure-sensitive, capacitive relies on electrical properties of the human body). **Scanner:** Allows for input through optical character recognition (OCR). **Buffering:** In I/O devices, buffering helps to **bridge differences in data transfer speeds**. **Hypervisor:** Virtualized I/O devices are managed by the **Hypervisor**. **Dot Matrix Printer:** Best suited for high-speed multi-copy forms.

### 4. Computer Software - OS and Utility Programs **Virtual Memory:** Its primary role is to **extend RAM using disk space**. **Real-Time OS:** Specifically designed to respond quickly to external events. **BIOS:** During boot-up, the first software to load into the system memory is the BIOS. **File Compression:** Utilities that **reduce file size for storage and transfer**. **Scheduler:** The OS component responsible for allocating processor time to tasks.

### 5. Computer Software - Applications and Programming Software **Open Source:** A software license that allows modification and redistribution of the source code. **Compilers:** Differ from interpreters because they **convert high-level code to machine code before execution**. **IDE:** A software development tool that enables both coding and debugging within a single interface. **SaaS (Software as a Service):** Characterized by **Cloud-based delivery**. **Simulation Programs:** Designed to **emulate real-world behavior in a controlled environment**.

### 6. Virtualization **Server Virtualization:** Allows a single physical device to serve multiple applications simultaneously by creating isolated environments. **Hypervisor Role:** To **manage communication between virtual and physical devices**. **Disadvantage:** Increased physical space requirements is **NOT** an advantage of virtualization. **Hypervisor:** Defines the boundary between a host OS and a guest OS. **Storage Virtualization:** Achieves scalability primarily through the **logical pooling of storage resources**.

### 7. Internetworking **Bandwidth:** Represents the maximum theoretical speed at which data can be transmitted between nodes. **Fiber-optic Cables:** Outperform traditional copper cables by having minimal **signal degradation over long distances**. **Subnet Mask:** For IP `192.168.1.1/24`, the subnet mask is **255.255.255.0**. **Switch:** Manages traffic within a LAN by using MAC addresses. **Wi-Fi:** Allows a device to share its Internet connection wirelessly within a short range.

### 8. Cybersecurity Awareness **WannaCry Ransomware:** Exploited vulnerabilities in **unpatched SMB protocols**. **Mirai Botnet:** Responsible for **Distributed Denial-of-Service (DDoS)** attacks. **Ethical Hacking:** Contributes to cybersecurity by **proactively identifying and resolving system flaws**. **Phishing Prevention:** A best practice is **verifying email senders before clicking on links**. **Ethical Responsibilities:** Maintaining the **confidentiality of user data** is a primary computing ethic.

### 9. Software Development Process **Waterfall Disadvantage:** Compared to Agile, its primary disadvantage is **inflexibility to accommodate changes mid-project**. **Design Phase:** The SDLC phase where design documents like UML diagrams are created. **DevOps:** Emphasizes **continuous integration and delivery** (CI/CD). **Integration Testing:** Performed to ensure different software modules interact correctly. **Agile over Waterfall:** The key factor to choose Agile is **high team flexibility** (and changing requirements).

### 10. Databases **Network Database:** Best suited for storing highly interconnected data with multiple parent-child relationships. **Foreign Key:** In a relational database, it **establishes a link between tables**. **DELETE (or DROP):** The SQL command used to remove data from a table permanently (Note: `DROP` removes the table, `DELETE` removes rows. Option contextually usually refers to `DELETE` or `DROP`). **NoSQL Advantage:** A key advantage over relational databases is **horizontal scalability**. **Index:** The database component that improves data retrieval speed by maintaining a map of table data.
