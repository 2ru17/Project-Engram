## Common Pitfalls

Studying sub-topics in isolation — **Arrays**, **Dimensions**, and **Advantages/Disadvantages** are interconnected and best understood together
Jumping to advanced operations (pointers, functions) before understanding basic declaration, initialization, and traversal
Ignoring the **trade-offs** in the Advantages and Disadvantages note — knowing when _not_ to use arrays is as important as knowing how to use them

    - **B)** Writing too many comments in the code
    - **C)** Forgetting to include standard libraries

3. What is emphasized regarding the trade-offs in the Advantages and Disadvantages note?
    - **A)** Knowing when to avoid using arrays is as important as knowing how to use them

### Answer Key & Explanations
1. **B)** The document groups the topic logically into basics, dimensionality, and performance trade-offs.
2. **A)** It stresses learning core principles like initialization before diving into pointer arithmetic.
3. **A)** Recognizing situations where an array's limitations outweigh its speed benefits is crucial.
