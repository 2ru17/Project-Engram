## Key Definitions
 What we’ve done so far... Creating HTML documents Styling documents with CSS Automating Actions and behavior using JavaScript/jQuery. They are all files!
 Client-Server Architecture The Client-Server Architecture is composed of: The client – a machine or program that allows users to make requests through the Web The server – a program that serves the requests of multiple clients
 Front-end Frameworks With the knowledge of basic HTML, CSS, and JS, you can build a client-side website. But there are other libraries and frameworks that can make it easier for you.
 Front-end CSS Frameworks These are premade CSS design rules to help organize and layout content for development
 Front-end JS Frameworks Collection of prewritten JS code to help in building web applications Provides rules and structure on how to organize the web application

## Theoretical Framework

> Front-end JS Frameworks
> Some of these JS frameworks also provide a good base for client-server communication.

> What is NodeJS?
> Open-source JavaScript runtime environment that enables JavaScript to be executed outside a browser
> what is a runtime environment?

> JavaScript Origins
> JavaScript was originally developed to build web applications for browsers.
> The Browsers serve as runtime environments for JavaScript

> JS Engine
> A program that interprets high-level JavaScript syntax to machine-bytecode.

> JS Engine
> Different browsers have different engines, which is why sometimes JS code behaves differently in some browsers.

## Multiple Choice Questions

1. In the Client-Server Architecture, what is the role of the server?
    - **A)** A machine or program that makes requests through the Web.
    - **B)** A program that serves the requests of multiple clients.
    - **C)** A runtime environment embedded specifically inside browsers.
    - **D)** A collection of prewritten JS code to help build web applications.

2. What is NodeJS?
    - **A)** An open-source JavaScript runtime environment that enables JavaScript to be executed outside a browser.
    - **B)** A front-end CSS framework used for premade design rules.
    - **C)** A JS Engine developed exclusively to run inside Google Chrome.
    - **D)** A relational database system commonly used with JavaScript.

3. What does a JS Engine do?
    - **A)** It translates HTML and CSS into visual web pages.
    - **B)** It manages client-server routing protocols.
    - **C)** It interprets high-level JavaScript syntax into machine-bytecode.
    - **D)** It serves static files to clients automatically.

### Answer Key & Explanations
1. **B)** The server is a program that serves the requests of multiple clients, whereas the client makes the requests.
2. **A)** NodeJS is an open-source JavaScript runtime environment that allows JavaScript to run outside of web browsers.
3. **C)** A JS Engine is a program that interprets high-level JavaScript syntax to machine-bytecode.
